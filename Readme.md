# 🎥 Zen Tab Video 
> Transform your New Tab into a cinematic, minimalist, and fluid experience.

**Zen Tab Video** is a Chrome and Brave extension that replaces the boring "New Tab" screen with a custom video background, an elegant clock, and a "glassmorphic" settings panel. Fully optimized for zero-lag performance using **IndexedDB** and **Blob URLs**.

## ✨ Features
- 🕒 **Real-time Clock:** 24h format with integrated date display.
- 🎬 **Custom Video Background:** Upload your own video (WebM/MP4).
- ⚡ **Ultra Lightweight:** Instant loading with zero delay (Zero Lag).
- 🎨 **Glassmorphism UI:** Modern sidebar with background blur effects.
- 🛠 **Opacity Control:** Adjust video transparency for better readability.

## 🚀 Installation (Step-by-Step)

Follow these simple steps to run this extension in your browser:

1.  **Download the Project:** 
    - Clone this repository: `git clone https://github.com`
    - Or simply [Download the ZIP](https://github.com) and extract it on your PC.

2.  **Open Extensions Management:**
    - On **Chrome**: go to `chrome://extensions/`
    - On **Brave**: go to `brave://extensions/`

3.  **Enable Developer Mode:**
    - Look for the **"Developer mode"** toggle in the top right corner and turn it on.

4.  **Load the Extension:**
    - Click the **"Load unpacked"** button.
    - Select the folder where you downloaded/extracted the files.

**Done!** Open a new tab (`Ctrl + T`) and enjoy.

## 🛠️ Settings
To customize your experience, click the menu icon (**☰**) in the top right corner:
- **Select Video:** Choose any video file from your local drive.
- **Opacity:** Slide to adjust background brightness.
- **Reset:** Revert to the default state in one click.

---

## 💡 Optimization Tips
To keep the extension lightning-fast and save RAM:
- Use **.webm** format (significantly lighter than .mp4).
- Recommended resolution: **1080p at 30fps**.
- Try to keep file size under **10MB** for instant, "zero-wait" loading.
